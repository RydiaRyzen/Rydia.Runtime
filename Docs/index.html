01 / OVERVIEW

開発者のための、
柔軟なエンジン。

Rydia Engineの目的は、ゲームやグラフィックスアプリケーションを構築するための土台を提供することです。共通のAPIとプラットフォームごとの実装を整理し、開発に集中できる構成を目指します。

02 / FEATURES

プロジェクトの成長に合わせて拡張できる、
開発基盤を目指しています。

01
◈

Graphics

WindowsはGoogle AngleとOpenGL ESを利用した描画基盤。 MacOS はMetalを利用した描画基盤。 Linux はOpenGLを利用した描画基盤。 AndroidはOpenGL ESを利用した描画基盤。 iOS はMetalを利用した描画基盤。 リアルタイムグラフィックスの実装を支えます。
